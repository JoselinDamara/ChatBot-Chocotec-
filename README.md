# Chatbot Inteligente con IA

Proyecto de automatización desarrollado con n8n y Telegram.

## Características
- Integración con Cohere API
- Base de datos MySQL en Railway
- Automatización de respuestas
- Memoria conversacional
- Uso de Vector Store
- Comunicación mediante Telegram Bot

## Tecnologías
- n8n
- MySQL
- Railway
- Cohere API
- Telegram Bot
- APIs REST
- AI Agent

## Arquitectura
Usuario -> Telegram -> n8n -> Cohere API -> MySQL (Railway)

## Funcionalidades
- Respuestas automáticas inteligentes
- Consulta de información desde base de datos
- Gestión conversacional mediante IA
